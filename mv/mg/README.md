# 四季之歌 · MG 版

《四季之歌》的扁平纸艺风格 MG 动画 MV，全部画面由 Canvas 代码逐帧绘制。

- 打开 `index.html` 可以直接在浏览器里预览，地址后加 `?t=秒数` 从指定位置开始播放（不带音乐）
- `node preview.mjs <输出目录> 10 12.5 30:40:0.5`：渲染指定时刻的静帧，用来检查画面
- 成片：
  1. 分段渲染：`node render.mjs part0.mp4 30 0 2690`，后两段依次是 `2690 5380`、`5380 8070`，可以并行跑
  2. 合成音轨：`sh mux.sh <音频> <成片.mp4> part0.mp4 part1.mp4 part2.mp4`

## 文件

| 文件 | 内容 |
| --- | --- |
| `core.js` | 缓动函数、节拍时钟（实测约 92.5 BPM）、配色、基础图形、逐字入场的歌词 |
| `chars.js` | 角色骨架（侧面、正面、背面）、大侧脸剪影、手、拉钩的手、海鸥、帆船、花、树 |
| `scenes1.js` | 0–52 秒：前奏、第一段主歌、副歌一 |
| `scenes2.js` | 52–125 秒：第二段主歌（夏天的回忆）、第二段 A 段、副歌二（一镜到底横穿四季） |
| `scenes3.js` | 125–167 秒：桥段、间奏、两段高潮 |
| `scenes4.js` | 167–269 秒：副歌三（重逢）、副歌四（照片墙）、最后一段主歌（列车、纸飞机）、尾奏 |
| `timeline.js` | 分镜表、转场合成、歌词时间轴、成片质感 |

歌词时间轴来自原视频的字幕。字体是霞鹜文楷，只保留了用到的字，许可见 `fonts/OFL.txt`。
