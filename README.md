# 街头王者 3V3

浏览器里的 3D 半场三对三街球游戏，玩法参照街球手游的核心规则：清球、12 秒进攻、计时出手条、盖帽抢断、角色技能、火热手感。电脑和手机都能玩。

所有角色、队名和美术都是原创的，与任何商业游戏或 NBA 球员无关。

## 怎么玩

直接用浏览器打开 `index.html`，需要联网加载 three.js。

| 操作 | 键盘 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左半屏摇杆 |
| 投篮（持球） | 按住 J，指针到绿区松开 | 按住「投篮」 |
| 盖帽 / 抢板（无球） | J | 同一个按钮 |
| 传球 / 要球 / 抢断 | K | 「传球」按钮，标签随局面变化 |
| 突破变向 / 冲刺 | L 或 Shift | 「突破」按钮 |
| 角色技能 | I | 青色按钮 |
| 暂停 | P / Esc | 右上角 |

## 规则

- 先拿 21 分，或时间结束时（3 / 5 分钟可选）领先的一方获胜；平局进入加时，先得分者胜
- **清球**：抢到对手的篮板或断球后，必须先把球带出三分线，否则进球无效
- 进攻时限 12 秒，球碰框后重置
- 三分线外 3 分，线内 2 分
- 出手条停在绿区内松手是「完美出手」，命中率大幅提升；完美区间的宽度取决于球员的投篮能力
- 同一名球员连续命中 3 球进入「火热」状态，命中率提升，直到投丢为止

## 球员

| 球员 | 位置 | 进攻技能 | 防守技能 |
| --- | --- | --- | --- |
| 闪电 | 控球后卫 | 鬼魅变向：大幅变向，容易晃倒防守人 | 贴身紧逼：抢断率提升 |
| 神射 | 得分后卫 | 后撤步三分：完美区间翻倍 | 极速封堵：冲到持球人面前干扰 |
| 飞人 | 小前锋 | 战斧暴扣：6 米内腾空暴扣 | 追身大帽：冲刺起跳封盖 |
| 铁塔 | 中锋 | 背身勾手：几乎无法封盖 | 禁区之王：封盖和篮板大幅提升 |
| 野兽 | 大前锋 | 野蛮冲撞：撞开防守人直接扣篮 | 卡位抢板：篮板范围提升 |
| 鬼手 | 锋卫摇摆 | 急停跳投：完美区间翻倍，受干扰减半 | 鬼手抢断：闪身掏球 |

你选一名球员，系统会从剩下的五人里自动搭配两名队友，保证后卫和内线都有，另外三人组成对手。三档难度会影响对手的反应速度、出手质量、抢断频率和防守强度；你的队友始终按中等水平行动。

## 文件

- `game.html`：游戏全部代码（HTML + CSS + JS，单文件，渲染用 three.js r128）
- `index.html`：由 `node scripts/build.mjs` 从 `game.html` 生成的独立页面，改完 `game.html` 后重新运行一次

## 实现说明

- 角色用基本几何体拼成，配合卡通着色和描边；跑动、运球、跳投、扣篮、盖帽、被晃倒这些动作都是程序生成的
- 投篮是真实的抛物线；不中的球会按落点从篮筐弹出，有篮板争抢
- 音效和背景节拍全部用 Web Audio 实时合成，不需要音频文件
- AI 会拉开站位、空切、持球时绕开防守人突破、协防补位、起跳封盖、抢篮板，并在合适时机放技能（没有做挡拆配合）

和原作相比的主要差距：没有动作捕捉和高精度建模，没有联网对战，没有角色养成。
