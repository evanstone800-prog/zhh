# 街头王者 3V3

浏览器里的 3D 半场三对三街球游戏。玩法参照街球手游的核心规则：11 分赛、清球、进攻时限、按空位程度变化的出手条、挡拆、背打、卡位、张手防守、角色技能、攒士气放大招、切换操控球员。电脑和手机都能玩。

所有角色、队名和美术都是原创的，与任何商业游戏或 NBA 球员无关。

## 怎么玩

直接用浏览器打开 `index.html`，需要联网加载 three.js。

| 操作 | 键盘 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左半屏摇杆 |
| 投篮（持球） | 按住 J，弧形指针到绿区松开；轻点是假动作 | 按住「投篮」 |
| 盖帽 / 抢板（无球） | J | 同一个按钮 |
| 传球 / 空接 / 要球 / 抢断 | K | 「传球」按钮，标签随局面变化 |
| 突破变向 / 冲刺 | L 或 Shift | 「突破」按钮 |
| 战术键：背打 / 叫挡拆 / 去挡拆 / 张手 / 卡位 | H | 「挡拆」按钮，标签随局面变化 |
| 角色技能 | I | 青色按钮 |
| 大招（士气满后） | O | 金色按钮 |
| 切换操控的队友 | Q / Tab | 「切换」按钮 |
| 暂停 | P / Esc | 右上角 |

按键在不同局面下作用不同，界面上的按钮文字会跟着变：

- **持球**：离篮 5 米内按住 H 是背打——往篮筐方向推会一下下顶开防守人，J 转身投篮（内线勾手、外线后仰），L 转身过人，K 分球。更远时 H 是叫一名队友来挡拆。
- **无球进攻**：H 跑去给持球人挡拆，挡住后内线会下顺、射手会外弹。
- **防守**：按住 H 张手，干扰投篮、更容易断传球，但移动变慢。默认摇杆不动时自动跟防，可以在选人界面改成手动。
- **球在空中**：H 卡位，按太早（刚出手时）会僵直；抢篮板在球开始下落时起跳最好，地上的白圈是预测落点。

## 规则

- **11 分赛**（默认）：3 分钟内先拿 11 分获胜，时间到领先者胜；平局加时 1 分钟，再平则先得分者胜。也可以选 21 分赛
- **清球**：抢到对手的篮板或断球后，必须先把球带出三分线，否则进球无效
- 进攻时限：11 分赛 20 秒，21 分赛 12 秒，球碰框后重置
- 三分线外 3 分，线内 2 分
- 出手条停在绿区内松手是「完美出手」，命中率大幅提升。绿区宽度由球员投篮能力和**空位程度**决定：空位时明显变宽，被贴身或张手干扰时变窄，出手时屏幕上会标出「空位 / 轻微干扰 / 有干扰 / 严重干扰」
- 同一名球员连续命中 3 球进入「火热」状态，命中率提升，直到投丢为止
- **士气与大招**：得分、助攻、抢断、盖帽、篮板、完美出手、晃倒都会攒士气，满了可以放大招，持续 8–10 秒

## 球员

| 球员 | 位置 | 进攻技能 | 防守技能 | 大招 |
| --- | --- | --- | --- | --- |
| 闪电 | 控球后卫 | 鬼魅变向：大幅变向，容易晃倒防守人 | 贴身紧逼：抢断率提升 | 极速风暴：移速大增，变向很可能晃倒人 |
| 神射 | 得分后卫 | 后撤步三分：完美区间翻倍 | 极速封堵：冲到持球人面前干扰 | 无限射程：完美区间翻倍，超远三分不衰减 |
| 飞人 | 小前锋 | 战斧暴扣：6 米内腾空暴扣 | 追身大帽：冲刺起跳封盖 | 扣篮大赛：6.5 米内起飞，扣篮几乎无法封盖 |
| 铁塔 | 中锋 | 背身勾手：几乎无法封盖 | 禁区之王：封盖和篮板大幅提升 | 禁区霸主：封盖篮板范围暴涨，对手篮下命中下降 |
| 野兽 | 大前锋 | 野蛮冲撞：撞开防守人直接扣篮 | 卡位抢板：篮板范围提升 | 蛮牛冲撞：持球突破撞翻防守人 |
| 鬼手 | 锋卫摇摆 | 急停跳投：完美区间翻倍，受干扰减半 | 鬼手抢断：闪身掏球 | 幻影之手：抢断与断球能力暴涨 |

你选一名球员，系统会从剩下的五人里自动搭配两名队友，保证后卫和内线都有，另外三人组成对手。三档难度会影响对手的反应速度、出手质量、抢断频率和防守强度；你的队友始终按中等水平行动。

## 文件

- `game.html`：游戏全部代码（HTML + CSS + JS，单文件，渲染用 three.js r128）
- `index.html`：由 `node scripts/build.mjs` 从 `game.html` 生成的独立页面，改完 `game.html` 后重新运行一次

## 演出与细节

- **开场**：两队亮相，带球员头像的 VS 介绍
- **技能特写**：放技能时角色头像横幅划过屏幕
- **精彩回放**：花式扣篮、空接、盖帽、晃倒、绝杀之后自动播放慢动作回放，镜头环绕，点一下可跳过
- **扣篮**：单手、双手、战斧、风车、360°、反身，扣完会挂框，镜头推近、篮筐震动、闪屏
- **运球**：交叉、胯下、背后三种变向，球真的从手到手走一遍
- **篮筐物理**：球和篮圈、篮板有真实碰撞，会弹框、滚筐进、打板；三不沾会有提示
- **布料篮网**：用质点弹簧模拟，球穿过时会被撑开、甩动
- **空接**：队友切到篮下时传球自动变成高吊，接球直接空中扣篮
- **投篮假动作**：轻点投篮键，防守人可能起跳上当
- **事件播报**：左侧滚动显示得分、抢断、盖帽、晃倒、挡拆、大招
- **文字解说**：屏幕下方按场上事件出解说词（暴扣、追平、反超、最后一分钟等）
- **大招特写**：放大招时有全屏横幅和镜头推近，球员脚下冒光，名字后标「爆发」
- **场上提示**：防守时你盯的人脚下有青色圈；篮板预测落点白圈；队友空位时会喊「空位」或「空接」
- **赛后数据**：每名球员的得分、篮板、助攻、抢断、盖帽、命中、三分和评分（S–D），以及两队命中率等汇总
- **场景**：夜间街头球场、探照灯、灯串、涂鸦墙、滚动 LED 屏、霓虹招牌、看台观众（得分时举手欢呼）、DJ 台音箱随节拍跳动
- **声音**：运球、球鞋摩擦、篮网刷声、打框、扣篮、观众欢呼和惊呼、哨声、背景节拍，全部用 Web Audio 实时合成

## 实现说明

- 角色是带关节的骨架（髋、脊柱、头、肩、肘、腕、膝、踝），身体各部分用车削几何体做出肌肉轮廓，配卡通着色、描边和轮廓光
- 动作是分层的：跑动和防守滑步是程序化步态，投篮、扣篮、传球、抢断等是动作片段，头部会追踪球；球的位置取自手部骨骼
- 头像是用游戏里的模型实时渲染出来的
- AI 会拉开站位、空切、持球时绕开防守人突破、协防补位、起跳封盖、抢篮板、传空接，并在合适时机放技能和大招
- AI 内线会主动给持球人挡拆，挡完下顺或外弹；持球人会借掩护突破；防守方被挡住时可能换防
- 强壮的内线会背打，到时间后转身勾手、转身过人或分球；投篮出手后，篮下的人会卡位

和原作相比的主要差距：没有真实球员授权，没有动作捕捉和高精度建模，没有联网对战、王朝模式和角色养成，也没有语音解说。
